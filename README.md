# Leon - Creative Agency Website

A clean and responsive creative agency website built with HTML and CSS.

## 📌 Overview

Leon is a simple and modern agency website designed to showcase services, projects, and company information through a clean and responsive layout.

The project focuses on practicing semantic HTML, CSS layout techniques, responsive design, and organizing a multi-section website.

## ✨ Features

- Responsive navigation bar
- Hero / Landing section
- Features section
- Services section
- Portfolio section
- About Us section
- Contact section
- Footer
- Responsive layout for different screen sizes
- Smooth scrolling navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome
- Google Fonts
